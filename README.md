# Job Roadmap Service

## 1. 프로젝트 개요

이 프로젝트는 직업별 채용공고와 관련 직무 정보를 분석하여, 각 직업을 준비하는 데 필요한 역량, 기술 도구, 산업군별 특징, 학습 자료를 정리하는 개인 프로젝트입니다.

단순히 직업을 소개하는 것이 아니라, 실제 채용공고에서 반복적으로 나타나는 지원 자격, 우대사항, 기술 스택, 직무 내용을 바탕으로 직업별 준비 방향을 구조화하는 것을 목표로 합니다.

## 2. 프로젝트를 시작한 이유

고등학생이나 취업 준비생이 특정 직업에 관심을 가지더라도, 실제로 그 직업을 준비하기 위해 어떤 역량이 필요한지 파악하기는 쉽지 않습니다.

예를 들어 데이터 분석가라는 직업만 보더라도 금융, 헬스케어, 병원, 제조, 플랫폼 서비스 등 산업군에 따라 담당업무와 요구 역량이 달라집니다. 또한 Python, SQL, Tableau, GA4, PACS와 같은 기술 도구도 단순히 사용할 줄 아는 수준을 넘어, 어떤 업무에서 어떤 방식으로 활용되는지까지 이해할 필요가 있습니다.

따라서 이 프로젝트에서는 직업을 하나의 단순한 설명으로 정리하지 않고, 직업, 산업군, 기술 도구, 학습 자료를 나누어 체계적으로 정리하고자 합니다.

## 3. 프로젝트 목표

- 직업별 기본 정보와 하는 일을 정리합니다.
- 채용공고 데이터를 기반으로 공통 요구 역량을 도출합니다.
- 산업군별로 달라지는 담당업무, 우대사항, 기술 스택을 정리합니다.
- 직무에서 활용되는 기술 도구와 필요한 활용 수준을 정리합니다.
- 직업을 준비하기 위한 학습 자료와 실습 프로젝트 방향을 제안합니다.

## 4. 활용 데이터

이 프로젝트에서는 공개 API와 공공 데이터를 활용하여 직업 및 채용공고 정보를 수집합니다.

주요 활용 데이터는 다음과 같습니다.

- 공공기관 채용정보 API
- 청년일자리 채용정보 API
- 서울시 일자리 관련 공공데이터
- 직업 정보 및 학과 정보 관련 공개 데이터
- 채용공고 내 지원 자격, 우대사항, 직무내용 텍스트

수집한 데이터는 개인 프로젝트의 분석 및 학습 목적으로만 활용합니다.
