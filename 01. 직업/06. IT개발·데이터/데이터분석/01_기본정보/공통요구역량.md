# 공통요구역량

## 1. 문서 목적

이 문서는 해당 직업에서 산업군과 관계없이 반복적으로 요구되는 공통 역량을 정리한 문서입니다.  
수집한 직업 정보, 직무 설명 자료, 채용공고 기반 분석 결과를 바탕으로 작성합니다.

## 2. 분석 기준

- 여러 자료에서 반복적으로 등장한 역량을 우선 반영합니다.
- 특정 산업군에서만 나타나는 역량은 산업군별 문서에서 다룹니다.
- 자격증, 광고성 글, 개인 후기 중심의 내용은 제외합니다.
- 기술도구는 반복 등장 여부와 실제 직무 활용 가능성을 함께 검토합니다.
- 단순 빈도뿐 아니라 직무 수행과 직접 연결되는지를 기준으로 판단합니다.

## 3. 공통 업무 및 역량

주요업무근거와 업무특징근거를 함께 활용하여 문장 단위 군집화를 진행했고, 유사한 문장들이 묶인 결과를 바탕으로 공통 직무 역량을 정리했습니다.  
언급문서수는 해당 역량이 몇 개의 자료에서 반복적으로 확인되었는지를 의미합니다.

| 공통 직무 역량 | 언급문서수 |
|---|---:|---|
| 비즈니스 이해 및 문제 정의 | 27 |
| 업무 자동화 | 12 |
| 데이터 전처리 | 10 |
| 데이터 활용 시스템 구축 | 6 |
| 의사결정 지원 | 6 |
| 시각화 및 결과 전달 | 3 |

### 해석

- 비즈니스 이해 및 문제 정의가 가장 많이 언급되어, 데이터 분석가는 단순히 데이터를 처리하는 역할보다 분석 목적과 문제를 정의하는 역할이 중요하게 나타났습니다.
- 업무 자동화와 데이터 전처리는 반복적인 데이터 처리 업무와 연결되며, 실무에서 데이터를 안정적으로 활용하기 위한 기반 역량으로 볼 수 있습니다.
- 데이터 활용 시스템 구축, 의사결정 지원, 시각화 및 결과 전달은 분석 결과를 조직에서 활용 가능한 형태로 연결하는 역량으로 정리할 수 있습니다.

## 4. 공통 기술스택

### 분석 기준

기술도구는 블로그 기반 직무 설명 자료에서 추출한 기술 키워드를 정규화한 뒤, 반복 등장 여부를 기준으로 정리했습니다.

- 등장횟수 10회 이상: 상
- 등장횟수 5회 이상: 중
- 등장횟수 5회 미만: 하
- Database는 SQL의 하위 활용 역량으로 분류했습니다.
- Pandas는 Python의 하위 활용 라이브러리로 분류했습니다.
