# 공통요구역량

## 1. 문서 목적

이 문서는 해당 직업에서 산업군과 관계없이 반복적으로 요구되는 공통 역량을 정리한 문서입니다.  
수집한 직업 정보, 직무 설명 자료, 채용공고 기반 분석 결과를 바탕으로 작성합니다.

## 2. 분석 기준

- 여러 자료에서 반복적으로 등장한 역량을 우선 반영합니다.
- 특정 산업군에서만 나타나는 역량은 산업군별 문서에서 다룹니다.
- 자격증, 광고성 글, 개인 후기 중심의 내용은 제외합니다.
- 기술도구는 반복 등장 여부와 실제 직무 활용 가능성을 함께 검토합니다.
- 단순 빈도뿐 아니라 직무 수행과 직접 연결되는지를 기준으로 판단합니다.

## 5. 공통 기술스택

### 분석 기준

기술도구는 블로그 기반 직무 설명 자료에서 추출한 기술 키워드를 정규화한 뒤, 반복 등장 여부를 기준으로 정리했습니다.

- 등장횟수 10회 이상: 상
- 등장횟수 5회 이상: 중
- 등장횟수 5회 미만: 하
- Database는 SQL의 하위 활용 역량으로 분류했습니다.
- Pandas는 Python의 하위 활용 라이브러리로 분류했습니다.
